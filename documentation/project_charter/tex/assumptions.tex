The following list contains critical assumptions related to the implementation and testing of the project.

\begin{itemize}
  \item A suitable testing cloud environment will be available by the 3rd sprint cycle
  \item Access to the customer installation software will be provided by the 5th sprint cycle
  \item The customer will provide ample power and network connectivity for the installation of the software and web interface
  \item The installation site network infrastructure will allow TCP network traffic on port 8080/80/443
  \item Demo video of testing and system framework running will be available by the 4th sprint cycle
  \item Final presentation and testing will be available by the last sprint cycle
  \item Cloud environment vendor will be up and running by the 3rd sprint cycle
\end{itemize}
