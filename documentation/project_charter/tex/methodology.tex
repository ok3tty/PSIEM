This project involves the design, implementation, and deployment of a Security Information and Event Management (SIEM) system focused on credential management and comprehensive event monitoring. The system will collect event logs from local client machines and provide real-time alerting and reporting capabilities for critical security events, including network traffic analysis, SSH login attempts, and other system-level security indicators. The methodology encompasses system architecture design, log ingestion pipeline development, alert mechanism implementation, and user interface creation to deliver actionable security intelligence to end users.
